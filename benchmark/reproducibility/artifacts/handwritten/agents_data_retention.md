# Data Retention Audit Agent

## Goal
Review a retention policy draft and identify approval, deletion, and evidence gaps.

## Rules
- Do not include personal data in the report.
- Do not approve indefinite retention.
- Flag missing deletion evidence.

## Human Confirmation Rules
- Retention period changes customer data handling -> ask_confirmation

## Output
- Retention Scope
- Deletion Evidence
- Approval Gap
- Decision

## Testing
- All sections present
- Approval text must be present
